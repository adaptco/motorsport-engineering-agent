# MEA v3.6 Runtime Contract Harness Plan

## Objective

Deliver enforceable runtime contracts, deterministic event gates, resumable checkpoints, and a reproducible deployment container cut on top of the `v3.5.2` baseline.

## Scope

- runtime contract bundle and validation harness
- integration of event gates into control-plane/runtime loops
- container and compose topology for v3.6 delivery
- explicit compatibility guardrails during migration

## Workstreams

### Workstream 1 — Runtime Contract Bundle

Add:

- `contracts/runtime/agent_runtime_contract_bundle.schema.json`
- `contracts/runtime/README.md`

Required event families:

- `request.received`
- `run.created`
- `workflow.policy.screened`
- `plan.proposed`
- `plan.repaired`
- `plan.failed`
- `step.dispatched`
- `approval.resolved`
- `tool.requested`
- `tool.executed`
- `action.proposed`
- `action.repaired`
- `action.invalid`
- `state.transitioned`
- `checkpoint.persisted`
- `blocked`
- `resume.requested`
- `run.completed`
- `run.failed`
- `audit.bundle.written`

### Workstream 2 — Runtime Integration

Integrate schema + policy + budget gates into runtime flow.

Minimum requirements:

- `tool.requested` carries `idempotency_key`
- `state.transitioned` emitted after approved runtime steps
- `checkpoint.persisted` emitted for resumable boundaries
- invalid branches emit explicit `plan.failed` / `action.invalid`

### Workstream 3 — Container Cut

Add:

- `deploy/containers/mea-v3.6/Dockerfile`
- `deploy/compose/docker-compose.v3.6.yml`

Align topology to:

- browser/operator
- gateway
- control plane
- worker pool
- data plane

### Workstream 4 — Version + Docs

Update:

- `PRD.md`
- `VERSION.json`
- `pyproject.toml`

Document:

- baseline snapshot and deployment shape

## Compatibility Commitments

v3.6 is additive. Legacy critical endpoints remain available while event contracts are introduced.

## Verification

- `python -m pytest -q tests/test_runtime_contract_bundle.py`
- `python -m pytest -q tests/test_runtime_event_order.py`
- `docker compose -f deploy/compose/docker-compose.v3.6.yml config`
- `docker build -f deploy/containers/mea-v3.6/Dockerfile -t mea:v3.6 .`

## Exit Criteria

- runtime contracts enforceable at runtime
- resumable checkpoints and event-order guarantees verified
- reproducible v3.6 container cut validated
