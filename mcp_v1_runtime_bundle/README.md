# MCP V1 Runtime Bundle

This bundle contains a governed single-agent runtime scaffold for MCP V1.0.

## Included artifacts
- `generation-manifest.json`
- `schemas/generation-state.schema.json`
- `src/runtime/mcp-v1-runtime.ts`
- `Agent.md`
- `SKILL.md`
- `tool-registry.json`
- `PRD.md`
- `openapi/orchestration-agent.openapi.yaml`
- `Agents.md`
- `registry/agents.registry.json`

## Intent
Provide a concrete release bundle for evaluating a single-agent orchestration runtime against `PRD.md`, while freezing the state model, node contract, and API surface needed for later repo-wide generation.
